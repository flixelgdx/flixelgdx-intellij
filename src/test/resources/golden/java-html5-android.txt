# Java Game

A game made with [FlixelGDX](https://github.com/flixelgdx), written in Java.

## Project layout

| Path                       | What it is                                                                         |
|----------------------------|------------------------------------------------------------------------------------|
| `project.toml`             | The title, version, window size and platforms. Edit it by hand.                    |
| `core/`                    | Your game. Almost all of your code goes here.                                      |
| `html5/`                   | The launcher that starts the game in a web browser.                                |
| `android/`                 | The launcher that starts the game on an Android phone or tablet.                   |
| `assets/`                  | Images, sounds and other files that every platform shares.                         |
| `gradle/libs.versions.toml`| Every library and Gradle plugin of the game, in one version catalog.               |
| `buildSrc/`                | Build settings that every module shares, such as the Java version.                 |

## Run the game

You need no tools besides a JDK to start Gradle. The wrapper (`gradlew`, or `gradlew.bat` on Windows)
downloads everything else the first time, so the first build is slow.

| Platform | With Gradle                       |
|----------|-----------------------------------|
| Web      | `./gradlew :html5:run`            |
| Android  | `./gradlew :android:installDebug` |

If something does not build, run `./gradlew doctor`. It checks your setup and `project.toml`, and says how to fix
each problem it finds.

## Release a new build

Before you give a build to players, even a small fix, run `./gradlew bumpBuild`. It raises `build` in
`project.toml` by one, which Android and Google Play need to tell a newer build from an older one.
Change `version` there too when the update deserves a new version name.

## Add libraries

Add the library to `[libraries]` in `gradle/libs.versions.toml`, then add its name to the bundle of the module that
uses it, such as `core`:

```toml
[libraries]
my-library = { module = "com.example:my-library", version = "1.0.0" }

[bundles]
core = ["flixelgdx-core", "my-library"]
```

A Gradle plugin goes into the `buildsrc` bundle, and its `id("...")` line into the `plugins {}` block of the module
that uses it.
