# Java Game

A game made with [FlixelGDX](https://github.com/flixelgdx), written in Kotlin.

## Project layout

| Path                       | What it is                                                                         |
|----------------------------|------------------------------------------------------------------------------------|
| `project.toml`             | The title, version, window size and platforms. Edit it by hand.                    |
| `core/`                    | Your game. Almost all of your code goes here.                                      |
| `desktop/`                 | The launcher that starts the game in a desktop window.                             |
| `assets/`                  | Images, sounds and other files that every platform shares.                         |
| `gradle/libs.versions.toml`| Every library and Gradle plugin of the game, in one version catalog.               |
| `buildSrc/`                | Build settings that every module shares, such as the Java version.                 |

## Run the game

You need no tools besides a JDK to start Gradle. The wrapper (`gradlew`, or `gradlew.bat` on Windows)
downloads everything else the first time, so the first build is slow.

| Platform | With Gradle                       |
|----------|-----------------------------------|
| Desktop  | `./gradlew :desktop:run`          |

Use `./gradlew :desktop:debug` to start the desktop game with the framework's debugging tools.

If something does not build, run `./gradlew doctor`. It checks your setup and `project.toml`, and says how to fix
each problem it finds.

## Release a new build

Before you give a build to players, even a small fix, run `./gradlew bumpBuild`. It raises `build` in
`project.toml` by one.
Change `version` there too when the update deserves a new version name.

## Add libraries

Add the library to `[libraries]` in `gradle/libs.versions.toml`, then add its name to the bundle of the module that
uses it, such as `core`:

```toml
[libraries]
my-library = { module = "com.example:my-library", version = "1.0.0" }

[bundles]
core = ["flixelgdx-core", "my-library"]
```

A Gradle plugin goes into the `buildsrc` bundle, and its `id("...")` line into the `plugins {}` block of the module
that uses it.

=== desktop/build.gradle.kts (mode 644)
plugins {
  id("flixelgdx.kotlin-jvm")
  application
}

val gameFileName = "java-game"
val isMacOs = System.getProperty("os.name", "").lowercase().contains("mac")
val heapJvmArgs = listOf("-Xms8M", "-Xmx1G")
// WebGPU and SDL call native code, which Java only allows quietly when native access is enabled.
val nativeAccessJvmArgs = listOf("--enable-native-access=ALL-UNNAMED")

application {
  mainClass = "com.teststudio.javagame.backend.desktop.DesktopLauncherKt"
  applicationDefaultJvmArgs = heapJvmArgs + nativeAccessJvmArgs
}

dependencies {
  implementation(project(":core"))
  implementation(libs.bundles.desktop)
}

// Kotlin runs annotation processors through kapt, which a package can apply to this module.
plugins.withId("org.jetbrains.kotlin.kapt") {
  dependencies {
    "kapt"(libs.bundles.desktopProcessors)
  }
}

tasks.withType<JavaExec>().configureEach {
  // The game looks for the assets folder in the working directory.
  workingDir = rootProject.projectDir
  jvmArgs(heapJvmArgs + nativeAccessJvmArgs)
  if (isMacOs) {
    jvmArgs("-XstartOnFirstThread")
  }
  outputs.upToDateWhen { false }
}

tasks.register<JavaExec>("debug") {
  group = ApplicationPlugin.APPLICATION_GROUP
  description = "Runs the game in debug mode with the framework's debugging tools enabled."
  mainClass = application.mainClass
  classpath = sourceSets.main.get().runtimeClasspath
  systemProperty("flixel.mode", "debug")
}

// Builds one jar that holds the game, every library and the assets folder.
tasks.jar {
  archiveFileName = "$gameFileName-$version.jar"
  duplicatesStrategy = DuplicatesStrategy.EXCLUDE
  dependsOn(configurations.runtimeClasspath)
  from(configurations.runtimeClasspath.map { cp -> cp.map { if (it.isDirectory) it else zipTree(it) } })
  from(rootProject.file("assets"))
  exclude("module-info.class", "**/module-info.class")
  exclude("META-INF/INDEX.LIST", "META-INF/*.SF", "META-INF/*.DSA", "META-INF/*.RSA", "META-INF/maven/**")
  manifest {
    attributes("Main-Class" to application.mainClass, "Enable-Native-Access" to "ALL-UNNAMED")
  }
  doLast {
    archiveFile.get().asFile.setExecutable(true, false)
  }
}

tasks.startScripts {
  classpath = files(tasks.jar)
}

distributions {
  main {
    contents {
      val runtimeClasspath = configurations.runtimeClasspath
      exclude { it.file in runtimeClasspath.get().files }
    }
  }
}
